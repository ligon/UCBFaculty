#+AUTHOR: Ethan Ligon

* About This Package

The =ucbfaculty= package is intended for members of the UC Berkeley
Academic Senate Committee on Committees and a small group of related
users.  The package itself is open source and installable from PyPI,
but it requires access to a private data archive --- a shared Box
folder holding GPG-encrypted faculty data --- to do anything useful.
If you are not a current committee member, the application will
install successfully but will have nothing to read.

If you /are/ a current or incoming committee member, the rest of this
guide walks you through the one-time setup.

* Before You Begin

You will need to complete a few steps /before/ you can install and use
the application.  These only need to be done once.

Please have the following ready, then email *Linda Corley*
(=lindac@berkeley.edu=) with:

1. Your *=@berkeley.edu= email address* (so you can be given access
   to the Box folder).
2. Your *GPG public key* (see [[*GPG Key Pair]]).

Linda will share the data folder with you in Box and encrypt the
confidential data files to your key.  You will receive a Box
notification and a confirmation email before proceeding to
installation.

* The Data Folder in Box

The encrypted data archive lives in this shared Box folder:

https://berkeley.app.box.com/folder/410604666843

Sign in to Box with your CalNet ID.  Once the folder has been shared
with you it will appear under *All Files* (and under *Shared with
me*).  Campus policy classifies the archive as protection-level 3
data, which is why it is hosted in Box rather than on GitHub.

There are two ways to get the folder onto your computer.  Pick one:

- *Box Drive* (macOS and Windows; recommended).  Berkeley's standard
  desktop client keeps the folder on your disk automatically and
  picks up new data without you doing anything.
- *rclone* (any platform; the only option on Linux).  A command-line
  tool that mirrors the folder into a local directory whenever you
  ask it to.

Both are covered under [[*Get the Data]] below.

* GPG Key Pair

GPG is used to encrypt and decrypt the confidential faculty data.  You
need a personal key pair: the /public/ half is shared with Linda so she
can encrypt files for you; the /private/ half stays on your machine
and is used to decrypt them.

** Check for an Existing Key

You may already have a GPG key --- for example, if you use encrypted
email or have signed Git commits.  To check:

- *macOS:* Open *GPG Keychain* (installed with GPG Suite).  If you see
  an entry with your =@berkeley.edu= address and a key icon, you
  already have one.
- *Windows:* Open *Kleopatra* (installed with Gpg4win).  Look under
  *My Certificates* for a key with your =@berkeley.edu= address.
- *Linux:*
  #+begin_src sh
  gpg --list-secret-keys your.email@berkeley.edu
  #+end_src
  If output appears, you have a key.  If it says nothing, you need to
  generate one.

If you already have a key, skip ahead to [[*Export and Send Your Public Key]].

** Install GPG

- *macOS:* Install [[https://gpgtools.org][GPG Suite]] (provides =gpg= and a GUI keychain).
- *Windows:* Install [[https://gpg4win.org][Gpg4win]] (provides =gpg= and the Kleopatra GUI).
- *Linux (Debian/Ubuntu):*
  #+begin_src sh
  sudo apt install gnupg
  #+end_src
- *Linux (Fedora):*
  #+begin_src sh
  sudo dnf install gnupg2
  #+end_src

** Generate Your Key

*** macOS (GPG Keychain)

GPG Suite includes *GPG Keychain*.  Open it and click *New*:
- Enter your full name (as it appears in the campus directory).
- Enter your =@berkeley.edu= email address.
- Choose a passphrase --- you will enter it each time you launch the
  app.
- Accept the defaults for everything else and click *Generate Key*.

*** Windows (Kleopatra)

Gpg4win includes *Kleopatra*.  Open it and choose *New Key Pair*:
- Select *Create a personal OpenPGP key pair*.
- Enter your full name and =@berkeley.edu= email address.
- Click *Advanced Settings* and ensure the key size is at least 3072
  bits, then click *Create*.
- Choose a passphrase when prompted.

*** Linux (command line)

#+begin_src sh
gpg --full-generate-key
#+end_src

When prompted:
- Key type: accept the default (RSA and RSA).
- Key size: =3072= or =4096=.
- Expiration: =0= (does not expire) is simplest.
- Real name: your full name as it appears in the campus directory.
- Email: your =@berkeley.edu= address.
- Passphrase: choose something memorable --- you will enter it each
  time you launch the app.

** Export and Send Your Public Key

*** macOS (GPG Keychain)

In GPG Keychain, right-click your key and choose *Export*.  Make sure
*Include secret key* is *unchecked*.  Save the file and email it to
=lindac@berkeley.edu=.

*** Windows (Kleopatra)

In Kleopatra, right-click your key and choose *Export...*.  Save the
file and email it to =lindac@berkeley.edu=.  (This exports only the
public half by default.)

*** Linux (command line)

#+begin_src sh
gpg --armor --export your.email@berkeley.edu
#+end_src

Copy the entire output (including the =-----BEGIN PGP PUBLIC KEY
BLOCK-----= and =-----END PGP PUBLIC KEY BLOCK-----= lines) and email
it to =lindac@berkeley.edu=.

* Install Prerequisites

You need *Python* (>=3.11), *GPG* (covered above), and one of *Box
Drive* or *rclone* (covered under [[*Get the Data]]).  Git is no longer
required.

** macOS

1. *Python 3.11+:* download from https://www.python.org/downloads/ and
   run the installer.
2. *GPG:* see [[*Install GPG]] above.

** Windows

1. *Python 3.11+:* download the Windows x64 installer from
   https://www.python.org/downloads/.  *Check "Add Python to PATH"*
   during installation.
2. *GPG:* see [[*Install GPG]] above.

** Linux

Python 3.11+ and GPG are likely already installed.  Verify with:

#+begin_src sh
python3 --version   # should be 3.11 or later
gpg --version
#+end_src

If Python is too old, see https://www.python.org/downloads/ or use
your distribution's backports.

* Get the Data

** Option 1: Box Drive (macOS / Windows, recommended)

1. Install Box Drive from https://www.box.com/resources/downloads
   (campus-managed machines may already have it).
2. Sign in with your =@berkeley.edu= address; Box will send you
   through CalNet.
3. Open the [[https://berkeley.app.box.com/folder/410604666843][data folder]] in a browser once.  Shared folders appear
   in Box Drive after you have opened them.
4. Find the folder on disk:
   - *macOS:* =~/Library/CloudStorage/Box-Box/= (older Box Drive
     versions use =~/Box/=).
   - *Windows:* =C:\Users\<you>\Box\=.
   Optionally right-click the folder and choose *Make Available
   Offline* so first-time loads are not slowed by on-demand downloads.

The setup wizard (see [[*First Run]]) looks in these locations and fills
in the path for you.

** Option 2: rclone (any platform; required on Linux)

1. Install rclone: https://rclone.org/install/ (=brew install rclone=,
   =sudo apt install rclone=, or the Windows installer).
2. Run:
   #+begin_src sh
   ucbfaculty sync
   #+end_src
   The first time, this creates an rclone remote named =ucbfaculty=
   pointed at the shared folder and opens a browser for Box sign-in.
   On Box's page choose *Sign in with SSO* (or enter your
   =@berkeley.edu= address) to go through CalNet, then click *Grant
   access*.  rclone then mirrors the folder into =~/.ucbfaculty/data=
   and writes the config file for you.
3. Run =ucbfaculty sync= again whenever you want to pick up new data
   (the app's Settings tab has a button that does the same).

If the browser cannot reach the link rclone prints (for example on a
remote machine), run =rclone authorize box= on a machine with a
browser and paste the result, as described at
https://rclone.org/remote_setup/.

** Option 3: A git-hosted archive

Deployments that host the archive in a git repository instead of Box
can use:

#+begin_src sh
ucbfaculty sync --backend git --repo-url https://example.edu/org/RawData.git
#+end_src

This clones (later: pulls) the repository into =~/.ucbfaculty/data=
and records =data_backend: git= in the config.

* Upgrading from the GitHub-based setup

Until September 2026 the archive was a private GitHub repository
that the app cloned to =~/RawData=.  If you installed before then,
the app still works from that clone, but the repository is being
retired and will stop receiving new data.  Moving takes three steps;
see =UPGRADE.org= for a step-by-step version written for people who
have never used a terminal.

1. Upgrade the package:
   #+begin_src sh
   pipx upgrade ucbfaculty
   #+end_src
2. Connect to Box and repoint the app.
   - *macOS / Windows:* install Box Drive and open the data folder
     once (see [[*Option 1: Box Drive (macOS / Windows, recommended)]]), then
     #+begin_src sh
     ucbfaculty init --force
     #+end_src
     which finds the folder inside Box Drive and rewrites the config.
   - *Linux (or rclone anywhere):*
     #+begin_src sh
     ucbfaculty sync --backend rclone
     #+end_src
     which connects rclone to Box (CalNet sign-in), mirrors the folder
     to =~/.ucbfaculty/data=, and rewrites the config to use it.
   Either command keeps unrelated settings (for example a COMS sheet
   key) and only replaces the data-directory entries.
3. Delete the old clone (=~/RawData=), which is now just a stale copy
   of confidential data.  Your GPG key and passphrase are unchanged.

Until you do this, the app's Settings tab prints a reminder every
time you click *Sync Data*.

* Install the Application

There are two ways to install UCBFaculty.  Choose the one that fits
your needs.

** Option A: Pre-built binary (easiest)

A maintainer may provide a ready-to-run executable for macOS or
Windows.  If you have received one:

- *No other software required* (besides GPG and Box Drive, covered
  above).  Python is bundled inside the binary.
- Double-click (or run from the terminal) to launch.
- Upgrades require downloading a new binary from the maintainer.

*Limitations:* You only get the web-based UI.  The =ucbfaculty=
Python library is not available for scripting or use by other tools.

** Option B: Install as a Python package (more flexible)

This installs =ucbfaculty= as both a command-line application /and/ a
Python library.  It requires *Python 3.11+* (see [[*Install Prerequisites]]).

Advantages over the pre-built binary:

- The full =ucbfaculty= Python library is importable, so you (or an
  LLM coding assistant such as Claude or ChatGPT) can write scripts
  against the data --- for example, building custom reports or running
  ad-hoc queries.
- Upgrades are a single command.
- Works on Linux, macOS, and Windows.

*** Using =pipx= (recommended)

=pipx= installs Python applications in isolated environments with a
single command.

#+begin_src sh
# Install pipx if you don't have it
python3 -m pip install --user pipx
python3 -m pipx ensurepath    # adds ~/.local/bin to your PATH
#+end_src

Then install UCBFaculty from PyPI:

#+begin_src sh
pipx install ucbfaculty
#+end_src

This gives you the =ucbfaculty= command.  To upgrade later:

#+begin_src sh
pipx upgrade ucbfaculty
#+end_src

*** From a source checkout

If you prefer to work from the source tree directly:

#+begin_src sh
git clone https://github.com/ligon/ucbfaculty.git ~/UCBFaculty
cd ~/UCBFaculty
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install .
#+end_src

* First Run

Launch the app:

#+begin_src sh
ucbfaculty --show
#+end_src

If no configuration file exists yet, a *Setup Assistant* opens in your
browser automatically.  It will:

1. Check that GPG and a secret key are available.
2. Show your public key (in case you still need to send it to Linda).
3. Get the data: detect the folder in Box Drive, or connect rclone to
   Box and mirror the folder (you will be asked to sign in with
   CalNet).
4. Write =~/.ucbfaculty/config.yaml= with the correct paths.

After setup completes, restart the app:

#+begin_src sh
ucbfaculty --show
#+end_src

Enter your GPG passphrase on the splash screen to unlock the data.

** Already have the data on disk? Skip the wizard.

If the folder is already on your machine (Box Drive is set up, you
ran =ucbfaculty sync=, a colleague handed you a copy, ...), you can
write the config file directly from the terminal:

#+begin_src sh
ucbfaculty init --data-dir /path/to/the/folder
#+end_src

If the folder is inside Box Drive, at =~/.ucbfaculty/data=, at
=~/RawData=, or is a sibling of the UCBFaculty install, you can omit
=--data-dir= and the command will find it automatically:

#+begin_src sh
ucbfaculty init
#+end_src

Either form writes =~/.ucbfaculty/config.yaml=, after which =ucbfaculty
--show= will launch the real application instead of the wizard.

* Subsequent Sessions

#+begin_src sh
ucbfaculty --show
#+end_src

That is all.  With Box Drive, new data arrives on its own.  With
rclone, click *Sync Data* on the Settings tab inside the app (or run
=ucbfaculty sync=) to pick up new files.

* Troubleshooting

- *"No secret key" when decrypting:* Your GPG key is missing or was
  generated under a different user account.  Re-run =gpg
  --full-generate-key= and send the new public key to Linda.
- *The Box folder is not in Box Drive:* Open the folder in a browser
  once (Box Drive only shows shared folders you have visited), then
  wait a minute for it to sync.  If it still does not appear, you may
  not have been given access yet --- check with Linda.
- *=ucbfaculty sync= says the authorisation has lapsed:* run
  =rclone config reconnect ucbfaculty:= and sign in again.
- *Setup wizard's "Get Data & Configure" tab is blank, or its Finish
  button stays greyed out:* run =ucbfaculty init= (or =ucbfaculty init
  --data-dir PATH=) from the terminal to write the config file
  directly.  See [[*Already have the data on disk? Skip the wizard.]].
- *Wrong data paths:* Edit =~/.ucbfaculty/config.yaml= or delete it
  and re-run the app to get the Setup Assistant again.
- *=ucbfaculty doctor= reports missing or undeclared files:* the local
  copy is out of step with the archive.  Sync again; if the report
  persists, tell the maintainer, since the archive itself may be
  inconsistent.
- *Port 5006 already in use:* Use =ucbfaculty --port 5007 --show= to
  pick a different port.

If you run into any other problems --- or if these steps do not resolve
the issue --- please open an issue at
https://github.com/ligon/UCBFaculty/issues.  Include a description of
what went wrong and any error messages you see; we will help you get
set up.
